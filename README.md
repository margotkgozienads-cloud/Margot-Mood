# Margot Mood V8

Application mobile-first en HTML/CSS/JS vanilla, partitionnée par page.

## Tester sur Chrome
1. Dézipper le dossier.
2. Ouvrir `index.html` dans Chrome.
3. Si Chrome bloque les imports ES modules en local, utiliser l'une de ces options :
   - VS Code > extension Live Server > Open with Live Server
   - GitHub Pages

## Structure
- `index.html` : coque de l'application
- `styles.css` : design global
- `app.js` : navigation, sauvegarde, points
- `data.js` : banques de données films, repas, idées mood
- `pages/` : une page = un fichier JS modifiable indépendamment

## Pages
Accueil, Mood, Hobbies, Sport, Nutrition, To-do, Culture, Courses, Appart, Envies, Profil.
