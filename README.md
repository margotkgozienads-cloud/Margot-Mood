# Margot Mood V8 reprise Pages

Version modulaire. Il faut mettre TOUS les fichiers du zip dans GitHub.

## Important
La racine du dépôt doit contenir :
- index.html
- styles.css
- app.js
- data.js
- dossier pages/

Ne pas uploader seulement index.html, sinon l'application sera vide ou cassée.

## Pour GitHub Pages
Settings > Pages > Deploy from branch > main > /root.

URL attendue si le repo s'appelle margot-mood :
https://margotkgozienads-cloud.github.io/margot-mood/

## Modifier une page
- Accueil : pages/home.js
- Mood : pages/mood.js
- Hobbies : pages/hobbies.js
- Sport : pages/sport.js
- Nutrition : pages/nutrition.js
- To-do : pages/todo.js
- Culture : pages/culture.js
- Courses/Appart/Envies : pages/simpleList.js
- Profil : pages/profil.js
