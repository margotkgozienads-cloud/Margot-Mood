Margot Mood V6

Contenu du pack :
- index.html : l'application
- manifest.json : configuration PWA
- sw.js : cache local simple

Pour l'utiliser sur iPhone :
1. Déposer le contenu du dossier sur un hébergeur gratuit comme Netlify ou GitHub Pages.
2. Ouvrir l'URL dans Safari sur iPhone.
3. Appuyer sur Partager.
4. Choisir Ajouter à l'écran d'accueil.

Version pensée mobile : textes simplifiés, compteurs multiples, récap de semaine, skincare quotidienne, grosse skincare du dimanche, watchlist et to do list.
