Firebase :
1. Créer un projet sur console.firebase.google.com.
2. Ajouter une application Web et copier firebaseConfig.
3. Activer Authentication > Email/Password.
4. Créer Firestore Database.
5. Coller firestore.rules dans Firestore > Rules.
6. Ouvrir l'app, Profil, coller firebaseConfig, créer un compte.
7. Se connecter avec le même compte sur PC et iPhone.

Après connexion, la synchronisation est automatique. L'export/import reste une sauvegarde de secours.
