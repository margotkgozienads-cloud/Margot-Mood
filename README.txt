Margot Mood V8 fonctionnelle

But de cette version : stabilité.
- Aucun Firebase.
- Aucun script externe.
- Fonctionne sur GitHub Pages, iPhone et PC.
- Sauvegarde locale dans le navigateur.
- Export / import JSON pour transférer les données entre appareils.

Fichiers à mettre à la racine du dépôt GitHub Pages :
- index.html
- manifest.json
- sw.js

Pour forcer l'affichage de la V8 après upload :
- ouvrir l'URL avec ?v=8
- supprimer puis réinstaller l'icône de l'écran d'accueil si besoin.
